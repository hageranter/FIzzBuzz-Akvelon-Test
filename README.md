# FizzBuzz Detector

- A C# console program
- Replaces every 3rd word with Fizz, every 5th with Buzz, and every 15th with FizzBuzz
- Returns the output string and the count of replacements
- Follows all instructions and constraints in the test document
- No built-in utilities or libraries used for the detection logic
- NO AI usage, only looking at C# doc for some syntax search
- Run with `dotnet run`
